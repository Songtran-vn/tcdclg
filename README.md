# App ôn tập Dạy Con Làm Giàu - GitHub + Vercel

Đây là bộ file đã chuẩn bị sẵn để upload lên GitHub rồi deploy bằng Vercel.

## File có trong gói
- `index.html`: app chính
- `vercel.json`: cấu hình cho Vercel
- `README.md`: mô tả dự án
- `HUONG_DAN_GITHUB_VERCEL.txt`: hướng dẫn cực ngắn từng bước

## Cách upload lên GitHub bằng web
1. Vào GitHub.
2. Tạo repository mới.
3. Chọn **Add file** > **Upload files**.
4. Kéo toàn bộ file trong thư mục này lên.
5. Nhấn **Commit changes**.

## Cách deploy bằng Vercel
1. Đăng nhập Vercel.
2. Chọn **Add New Project**.
3. Kết nối tài khoản GitHub nếu chưa kết nối.
4. Chọn repository vừa tạo.
5. Nhấn **Deploy**.

## Khi cập nhật nội dung
1. Sửa file `index.html`.
2. Upload lại lên GitHub hoặc commit/push.
3. Vercel sẽ tự deploy lại.


Phiên bản này đã sửa lỗi màu nền tối ở màn hình kết quả khi deploy lên Vercel.


## Bản cập nhật
- Đã sửa lỗi màu nền và màu chữ ở màn hình **Kết quả ôn tập** để hiển thị sáng, dễ đọc trên Vercel.
